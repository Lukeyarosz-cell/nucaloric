# Roadmap
## First: make the prototype consistent
- Retest all interactions using current selectors and actual visible drawer state.
- Use reliable local partner assets where redistribution is permitted.
- Label search and optimizer controls; establish page heading hierarchy.
- Implement command arrow/Enter navigation and drawer/modal focus return and trapping.
- Validate watchlist values and display a truthful empty state.
- Wire every launch selection into review; make all Apply buttons update their setting.
- Validate launch identity and structure before progression.
- Audit reduced motion and stop disposed quick-view canvas loops.

## Next: choose production architecture
- Define wallet authentication and session model.
- Define token deployment, transaction simulation, signing, confirmation, and failure UX.
- Define indexed market/holder data with timestamps and unavailable states.
- Define capability service contracts, permissions, hard limits, and health checks.
- Define rewards accounting and server-backed claim/referral verification.
- Define X integration only against confirmed available API capabilities.

## Completion evidence
A production feature must have a real integration contract, explicit loading/error/empty states, meaningful integration tests, and demonstrated behavior. UI labels alone do not establish integration availability.
