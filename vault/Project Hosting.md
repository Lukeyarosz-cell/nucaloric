# Project hosting

## Product direction
NUCALORIC should be a place to find and build useful Solana projects, with support for ongoing development after token launch. Hosting enables websites, apps, developer scripts, CLI workflows, and self-hosted inference associated with a project. Compute runs on servers; on-chain behavior runs on Solana.

## Implemented October 4, 2026
A dedicated Hosting page, global navigation and command search entry, homepage project-building section, and dashboard workspace entry. The configurator supports workload/compute selection, optional mint and public repository references, local saved plans, JSON export, and Bash setup script downloads. A configurable Paymenter checkout handoff remains disabled until real product URLs and prices are supplied.

## Required for production
An installed Paymenter portal with payment gateway, configured hosting provider/server extension, real CPU/GPU products and specifications, authenticated project membership, persistent service mappings, actual provisioning lifecycle, and service-scoped SSH/terminal access. No Paymenter installation or provider credentials have been supplied. The current website does not sell or provision servers or execute a live terminal.
